#

> In the [mathematical](https://en.wikipedia.org/wiki/Mathematics) field of [dynamical systems](https://en.wikipedia.org/wiki/Dynamical_system), an **attractor** is a set of states toward which a system tends to evolve,[[2]](https://en.wikipedia.org/wiki/Attractor#cite_note-2) for a wide variety of starting conditions of the system. System values that get close enough to the attractor values remain close even if slightly disturbed
 ([View Highlight](https://read.readwise.io/read/01hq77j0y0m9zvbt78xphq7mbs))

> If a set of points is periodic or chaotic, but the flow in the neighborhood is away from the set, the set is not an attractor, but instead is called a **repeller** (or *repellor*).
 ([View Highlight](https://read.readwise.io/read/01hq77p431sjjaytd58tdvx3k2))

> Some attractors are known to be chaotic (see [strange attractor](https://en.wikipedia.org/wiki/Attractor#Strange_attractor)), in which case the evolution of any two distinct points of the attractor result in exponentially [diverging trajectories](https://en.wikipedia.org/wiki/Chaos_theory), which complicates prediction when even the smallest noise is present in the system
 ([View Highlight](https://read.readwise.io/read/01hq77tz84jcm998h9cy5yvs7e))



#caos 

> An attractor's **basin of attraction** is the region of the [phase space](https://en.wikipedia.org/wiki/Phase_space), over which iterations are defined, such that any point (any [initial condition](https://en.wikipedia.org/wiki/Initial_condition)) in that region will [asymptotically](https://en.wikipedia.org/wiki/Asymptotic_behavior) be iterated into the attractor

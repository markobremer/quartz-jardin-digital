> The Evolution of Running
> • Walking is a pentagonal gait, which is different from running which is a hexagonal gait.
> • The adaptations that make walking better for running include a spring in the feet, a long achilles tendon, and a hip that is mechanically advantageous for running.
> • The main difference between walking and running is that walking allows the thorax to be moved independently of the hips, while running requires the entire upper body to rotate with the hips.

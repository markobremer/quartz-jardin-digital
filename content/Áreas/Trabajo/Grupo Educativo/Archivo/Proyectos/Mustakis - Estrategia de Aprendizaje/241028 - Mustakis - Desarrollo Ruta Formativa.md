# Actividad

## 1. Listado actividades mediador
- Elaborar un listado consensuado de las principales actividades que debe desarrollar un mediador.

## 2. Listado priorizado capacidades mediador
1. Cada participante revisa las propuestas de talleres previos: Motivaciones, Competencias y Experiencias.
2. Para cada lista, selecciona un máximo de 8 características que considera prioritarias. Puede crear un máximo de tres de esas 8.
3. Se repite tres veces ejercicio de priorización colectiva mediante eliminación. Quedan tres elementos en cada lista.

## 3. Distribución de elementos en las etapas de la ruta formativa y selección
- Se acuerda cuál es el lugar privilegiado para resolver cada una de las características y actividades.

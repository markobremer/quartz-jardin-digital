# Apuntes

La **desagregación por sexo** es el proceso de separar y analizar datos estadísticos en función del sexo biológico de las personas. Se utiliza para comprender diferencias en el acceso, uso y control de recursos, servicios y oportunidades entre hombres y mujeres, revelando posibles desigualdades.

Por su parte, el **análisis de género** es el proceso mediante el cual interpretamos y comprendemos las diferencias de género que se revelan en los datos desagregados por sexo. Este último es, entonces, un requisito para el primero. Este análisis es la base para el diseño de políticas y programas más equitativos.

Esta es la secuencia:

1. Desagregar datos por sexo.
2. Identificar y analizar diferencias.
3. Teorizar sobre sus causas.
4. Evaluar cómo afectan las oportunidades de cada grupo.
5. Proponer ajustes para corregir desigualdades.
